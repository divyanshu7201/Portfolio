## 🚀 Projects Showcased

Here is a breakdown of the key systems featured in my portfolio:

### 🎵 Spotify-Inspired Music Platform
A full-stack, responsive audio streaming application replicating the core user experience of Spotify.
* **Frontend**: Responsive grid layouts using React and Tailwind CSS.
* **Audio System**: Implemented interactive audio controller features (play, pause, seek, volume tracking) using the HTML5 Audio API.
* **Backend**: Express APIs and Node.js backend controllers to serve playlists and tracks dynamically.
* **Database**: MongoDB integration to manage user account data and track histories.
* **Key Tech**: `React` | `Node.js` | `Express` | `MongoDB`

### 📊 Customer Behaviour Analytics Platform
An end-to-end data analytics and machine learning pipeline to process and segment e-commerce transactions.
* **Data Synthesis**: Programmed custom Python traffic generators simulating customer profiles, web logs, and transaction streams.
* **ETL Pipeline**: Engineered a data loading pipeline using Pandas and NumPy.
* **Machine Learning**: Implemented unsupervised K-Means Clustering via Scikit-Learn to segment users into 4 distinct cohorts.
* **Visualization**: Designed database-linked Power BI dashboards for cohort retention heatmaps.
* **Key Tech**: `Python` | `MongoDB` | `ML (Scikit-Learn)` | `Power BI`

## ⚙️ Local Development Setup

To run this portfolio on your local machine:

1. **Clone the Repository**
   ```bash
   git clone https://github.com/divyanshu7201/Portfolio.git
   cd Portfolio
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Run Dev Server**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Production Build**
   ```bash
   npm run build
   ```
